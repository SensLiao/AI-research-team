<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| vault/search/director assets -> operated run | External references and files enter run-owned scratch under explicit scopes. |
| frozen snapshot -> worker DAG | Model workers receive only authorized immutable context slices. |
| worker/build/audit outputs -> director report | Untrusted outputs become claims only after schema, receipt, and deterministic truth gates. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-VLT | Elevation | recipe tools and destinations | critical | mitigate | Use bounded recall only; expose no database write, promotion, or director-gate invocation. |
| T-17-PTH | Tampering | run, asset, source, and packet paths | critical | mitigate | Resolve current-run roots and reject traversal, symlink, reparse, and cross-project escapes at each stage. |
| T-17-SEC | Information Disclosure | queries, worker prompts, errors, TeX, logs, Markdown | critical | mitigate | Pass references instead of credentials and apply shared redaction before record/render. |
| T-17-TEX | Elevation / Denial of Service | model-authored LaTeX and build | critical | mitigate | Preflight safe TeX, call only the shell-free bounded build wrapper, and preserve source-only delivery on failure. |
| T-17-TRU | Spoofing / Repudiation | citations, results, execution, PDF, status | critical | mitigate | Re-derive claims from exact evidence/result/executor/build hashes and deterministic audits. |
| T-17-DAG | Spoofing / Tampering | worker blindness and scheduler receipts | critical | mitigate | Verify role/stage/input/predecessor/contract hashes and exclude protected conclusions from blind auditors. |
