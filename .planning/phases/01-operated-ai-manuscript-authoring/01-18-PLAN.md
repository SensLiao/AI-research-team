<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authoring run -> review run | Immutable manuscript artifacts cross a cross-run reference boundary. |
| frozen manuscript -> blind reviewers | Protected author/reviewer conclusions must not leak into independent inputs. |
| reviewer bundles -> meta-verdict/director report | Model critiques become a verdict only after receipts and deterministic checks. |
