<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker bundles -> integrator | Model-authored text and claims cross into canonical state. |
| director assets -> run-owned assets | External files cross an immutable-copy and provenance boundary. |
| in-memory candidate -> source/ | Validated content crosses the single atomic writer boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-VLT | Elevation | canonical output target | critical | mitigate | Permit only the current run-owned source root; expose no vault write or promotion operation. |
| T-13-PTH | Tampering | paths, symlinks, and reparse points | high | mitigate | Resolve every source/destination under allowlisted roots and reject traversal or link escapes. |
| T-13-SEC | Information Disclosure | manuscript, BibTeX, manifests, logs | high | mitigate | Scan candidate text/metadata with shared redaction and fail before atomic publish. |
| T-13-TEX | Tampering / Elevation | LaTeX and generation commands | critical | mitigate | Reject dangerous TeX constructs; store argv receipts only and never invoke a shell here. |
| T-13-TRU | Spoofing / Repudiation | result numbers and PDF claims | critical | mitigate | Require frozen result/raw-receipt refs and emit no compiled-PDF claim from integration. |
| T-13-DAG | Spoofing / Tampering | bundle authorization receipts | high | mitigate | Verify role/stage/contract hashes and reject stale, duplicate, or undeclared slices. |
</threat_model>
