<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| machine evidence -> Markdown | Structured claims become human-facing statements and links. |
| canonical source -> latex presentation | Immutable source is projected for convenient review. |
| authoring run -> independent review reference | Cross-run evidence must retain distinct identities and hashes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-VLT | Elevation | rendered links/output roots | high | mitigate | Render only inside current run director-review and expose no vault write/promotion action. |
| T-16-PTH | Tampering | Markdown links and source projection | high | mitigate | Canonicalize bounded relative paths and reject traversal, symlink, reparse, or cross-run mismatches. |
| T-16-SEC | Information Disclosure | Markdown, URLs, logs, metadata | critical | mitigate | Apply shared redaction before rendering and fail secret-bearing output tests. |
| T-16-TEX | Tampering | projected TeX and command display | high | mitigate | Project only prevalidated canonical files/hashes and display argv receipts as inert text. |
| T-16-TRU | Spoofing / Repudiation | status, execution, PDF, review claims | critical | mitigate | Render validated reducer/build/review fields verbatim and require distinct review run/hash evidence. |
| T-16-DAG | Spoofing / Tampering | worker and review receipts | high | mitigate | Link receipt hashes and never infer independence from role labels or author self-report. |
</threat_model>
