<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted path/TeX/text -> deterministic validators | Papers, workers, paths, and TeX comments may attempt to expand authority. |
| run root -> sibling vault/director assets | Only bounded reads cross outward; all manuscript outputs remain run-owned. |
| worker prose -> execution truth | Model statements cannot establish experiment or PDF execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-VLT | Tampering / Elevation | vault and output paths | high | mitigate | Resolve/fence every target, reject vault and symlink/reparse escape, assert unchanged external inventories. |
| T-08-SEC | Information Disclosure | persisted text | high | mitigate | Scan every durable text channel with sentinel regressions and never read secret stores. |
| T-08-TEX | Elevation / Denial of Service | generated TeX | high | mitigate | Reject shell escape, external includes, arbitrary commands, and unbounded paths before compilation. |
| T-08-TRU | Spoofing / Repudiation | execution/PDF claims | high | mitigate | Require frozen auditable result facts here; build-specific PDF receipt checks follow in Plan 01-15. |
| T-08-DAG | Information Disclosure | worker scopes | high | mitigate | Validators accept only explicit run/slice roots and never discover broader worker context. |
| T-08-SC | Tampering | dependency supply chain | high | mitigate | Use Python standard library plus existing boundary modules; install nothing. |
</threat_model>
