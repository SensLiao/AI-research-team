## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker/tool payload -> dependency visibility | Untrusted JSON becomes schedulable evidence only after central validation. |

| payload refs -> vault/path/TeX/review truth | Structural validity complements, but never replaces, runtime truth gates. |
