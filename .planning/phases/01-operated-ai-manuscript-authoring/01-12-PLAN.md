<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PhD-Research-OS -> coverage router | Crown-jewel content crosses only as bounded, immutable references. |
| coverage deficit -> paper_search | Untrusted query/provider data crosses a network and logging boundary. |
| search metadata -> manuscript evidence | Metadata is not full-text evidence or entailment proof. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-VLT | Tampering / Elevation | recall roots and database seam | high | mitigate | Enforce bounded read-only refs and reject all write/promotion operations. |
| T-12-PTH | Tampering | paths, symlinks, and reparse points | high | mitigate | Resolve/canonicalize approved roots and reject escapes before recall. |
| T-12-SEC | Information Disclosure | queries, URLs, errors, logs | high | mitigate | Use non-query credentials and shared redaction on all returned diagnostics. |
| T-12-TEX | Tampering | retrieved text entering LaTeX | medium | mitigate | Return metadata-only structured fields; do not render untrusted text or invoke subprocesses here. |
| T-12-TRU | Spoofing / Repudiation | search/no-result/execution/PDF claims | high | mitigate | Keep typed provider receipts and forbid metadata from satisfying evidence, experiment, or PDF claims. |
| T-12-DAG | Tampering | worker evidence slices/receipts | high | mitigate | Bind coverage outputs to schema/hash and leave worker authorization to scheduler receipts. |
</threat_model>
