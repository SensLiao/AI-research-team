<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| machine -> PhD-Research-OS | Vault material is untrusted read-by-reference input; this phase has no vault writer or promotion authority. |
| worker -> scheduler/run store | Worker bundles cross a least-privilege boundary and become visible only after schema, scope, dependency-receipt, and hash checks. |
| manuscript source -> filesystem/TeX process | Generated TeX and asset paths are untrusted until run-root, symlink/reparse, directive, and subprocess checks pass. |
| scholarly provider -> persisted artifacts | Provider URLs and errors may contain secrets and must be sanitized before ledger, build, or director-facing persistence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-VLT | Tampering / Elevation | vault and run paths | high | mitigate | Agent never-scopes deny vault writes, promotion, downloads, shell/GPU execution, canonical-tree writes, and undeclared reviewer or predecessor data; preserve bounded tools/recall.py reads, run-owned writes, unchanged-vault assertions, and no promotion imports. |
| T-04-SEC | Information Disclosure | scholarly URLs, errors, logs, TeX, packets | high | mitigate | Persist only sanitized provider/path/status/request facts and run sentinel-secret scans before any artifact becomes durable. |
| T-04-TEX | Elevation / Denial of Service | TeX input and compiler subprocess | high | mitigate | Fence paths including symlink/reparse targets, reject unsafe TeX directives, use fixed argv with shell disabled and bounded time/output. |
| T-04-TRU | Spoofing / Repudiation | result and PDF claims | high | mitigate | Accept execution only from frozen auditable result refs; derive compiled state only from a current source hash, process receipt, existing PDF, and PDF hash. |
| T-04-DAG | Tampering / Information Disclosure | worker inputs and reviewer blindness | high | mitigate | Require scheduler authorization receipts, declared predecessor slices, frozen hashes, and blind reviewer scopes before dependency visibility. |
| T-04-SC | Tampering | dependency supply chain | high | mitigate | Run no package-manager install; use only the repository Python standard-library/jsonschema/pytest/run-store/scheduler stack. |
