<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manuscript/evidence/build inputs -> audit registry | Untrusted model and tool outputs are evaluated as claims, not trusted conclusions. |
| findings -> daily status | Deterministic severity policy controls readable delivery. |
| daily status -> submission readiness | A readable draft must not be confused with a submission-ready artifact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-VLT | Elevation | permission findings | critical | mitigate | Treat any vault write/promotion attempt as a hard permission finding. |
| T-14-PTH | Tampering | source/evidence/PDF paths | high | mitigate | Consume only canonical bounded paths and surface symlink/reparse escapes as hard findings. |
| T-14-SEC | Information Disclosure | reports and evidence excerpts | critical | mitigate | Scan/redact secrets before persistence; leakage is a hard daily block. |
| T-14-TEX | Tampering / Elevation | LaTeX/log/command evidence | high | mitigate | Require safe-source audit and argument-safe receipt; never execute a shell from the auditor. |
| T-14-TRU | Spoofing / Repudiation | citations, numbers, execution, PDF | critical | mitigate | Re-derive truth from exact source/result/executor/build hashes and reject prose assertions. |
