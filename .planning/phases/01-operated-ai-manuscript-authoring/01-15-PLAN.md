<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manuscript source -> TeX process | Model-authored source enters a native subprocess. |
| host tool discovery -> build runner | Untrusted PATH/environment selects an executable. |
| compiler outputs -> build truth | Logs/PDFs become claims only after freshness, status, and hash verification. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-VLT | Elevation | build cwd/output | critical | mitigate | Restrict build input/output to the current run and expose no vault/promotion target. |
| T-15-PTH | Tampering | executable/source/output paths | critical | mitigate | Canonicalize allowlisted roots and reject traversal, symlink, reparse, or cross-run paths. |
| T-15-SEC | Information Disclosure | argv, environment, logs, metadata | critical | mitigate | Use sanitized environment and shared secret redaction before any persisted diagnostic. |
| T-15-TEX | Elevation / Denial of Service | TeX subprocess | critical | mitigate | Preflight dangerous constructs, disable shell escape, pass argv with shell false, and enforce timeout/output caps. |
| T-15-TRU | Spoofing / Repudiation | execution/PDF status | critical | mitigate | Require fresh PDF plus source, command, log, and output hashes; never infer success from prose or stale files. |
| T-15-DAG | Tampering | build authorization/source receipt | high | mitigate | Bind the build to frozen contract/integration hashes and reject missing or mismatched receipts. |
</threat_model>
