<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment/provider request -> exception | Secret-bearing query data crosses from runtime configuration into an untrusted network failure. |
| exception -> paper_search/run artifacts | Diagnostic text becomes durable and potentially director-visible. |
| search metadata -> manuscript evidence | Metadata remains discovery-only and cannot become a citation or full-text source. |
