<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| machine -> PhD-Research-OS | Vault material is untrusted read-by-reference input; this phase has no vault writer or promotion authority. |
| worker -> scheduler/run store | Worker bundles cross a least-privilege boundary and become visible only after schema, scope, dependency-receipt, and hash checks. |
| manuscript source -> filesystem/TeX process | Generated TeX and asset paths are untrusted until run-root, symlink/reparse, directive, and subprocess checks pass. |
| scholarly provider -> persisted artifacts | Provider URLs and errors may contain secrets and must be sanitized before ledger, build, or director-facing persistence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-VLT | Tampering / Elevation | vault and run paths | high | mitigate | Fixtures use only temporary run roots and explicit read-only local evidence; expected failures cover vault/path, secret, TeX, truth, and receipt attacks; preserve bounded tools/recall.py reads, run-owned writes, unchanged-vault assertions, and no promotion imports. |
| T-03-SEC | Information Disclosure | scholarly URLs, errors, logs, TeX, packets | high | mitigate | Persist only sanitized provider/path/status/request facts and run sentinel-secret scans before any artifact becomes durable. |
| T-03-TEX | Elevation / Denial of Service | TeX input and compiler subprocess | high | mitigate | Fence paths including symlink/reparse targets, reject unsafe TeX directives, use fixed argv with shell disabled and bounded time/output. |
| T-03-TRU | Spoofing / Repudiation | result and PDF claims | high | mitigate | Accept execution only from frozen auditable result refs; derive compiled state only from a current source hash, process receipt, existing PDF, and PDF hash. |
| T-03-DAG | Tampering / Information Disclosure | worker inputs and reviewer blindness | high | mitigate | Require scheduler authorization receipts, declared predecessor slices, frozen hashes, and blind reviewer scopes before dependency visibility. |
| T-03-SC | Tampering | dependency supply chain | high | mitigate | Run no package-manager install; use only the repository Python standard-library/jsonschema/pytest/run-store/scheduler stack. |
</threat_model>
