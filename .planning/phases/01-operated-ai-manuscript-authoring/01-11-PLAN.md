<threat_model>
Coverage baseline: this plan keeps the vault/database read-only; rejects unsafe paths plus symlink/reparse escapes; redacts secrets from URLs and logs; treats TeX and subprocess use as deny-by-default unless the safe bounded adapter authorizes it; rejects false execution or PDF claims; and preserves worker blindness by validating authorization receipts against tampering.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| official/project/run overlays -> frozen contract | Lower-authority input may try to weaken official rules or inject paths/secrets. |
| frozen contract -> worker DAG | One hash authorizes all downstream context slices and invalidation. |
| configuration -> generic control plane | Domain/venue policy stays data-driven and cannot become permanent code truth. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-VLT | Tampering / Elevation | contract refs/paths | high | mitigate | Accept bounded hashed refs only, validate run ownership, and expose no write/promotion field. |
| T-11-SEC | Information Disclosure | overlay/contract text | high | mitigate | Persist source refs/hashes, not credentials; apply shared secret scan before freeze. |
| T-11-TEX | Tampering | build/template tokens | high | mitigate | Hard official engine/template/no-shell rules cannot be overridden by lower layers. |
| T-11-TRU | Spoofing / Repudiation | venue/result/PDF facts | high | mitigate | Freeze dated official sources and frozen result refs; contract contains policy, not execution/PDF proof. |
| T-11-DAG | Tampering / Information Disclosure | snapshot and slices | high | mitigate | One canonical hash and explicit descendants govern worker authorization and refresh. |
| T-11-SC | Tampering | dependencies | high | mitigate | Use standard library, PyYAML, jsonschema, and existing runstore only. |
</threat_model>
